# Web-Oriented User and Role Management System

## 📌 Project Description
This project is a web-oriented information system developed as part of an academic internship and bachelor’s thesis work.  
The system is designed to manage users, authentication, and role-based access using a client–server architecture.

The main goal of the project is to demonstrate practical skills in web development, system design, and client–server interaction.

---

## 🎯 Project Objectives
- Design and implement a web-based information system
- Apply client–server architecture principles
- Implement user registration and authentication
- Introduce role-based access control
- Work with a relational database
- Ensure basic system security

---

## 🧱 System Architecture
The system is built using a classic client–server architecture:

- **Frontend:** Web client for user interaction
- **Backend:** Server-side application with REST API
- **Database:** Relational database for persistent data storage


---

## ⚙️ Main Features
- User registration
- User authentication (login)
- User roles (user / admin)
- Protected routes based on user role
- User profile management
- Secure password storage

---
